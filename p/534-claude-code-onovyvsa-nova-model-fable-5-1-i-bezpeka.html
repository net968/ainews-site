Claude Code оновився: нова модель Fable 5.1 і безпека

01.09.2026 23:01

Anthropic випустила оновлення Claude Code v2.1.257. Головна новинка — Claude Fable 5.1, яка тепер стала моделлю за замовчуванням: контекст 1M токенів, ціна $10/$50 за Mtok і кеш-зчитування за $0.25. 📈 💡 Чому це важливо: Збільшення контексту до мільйона токенів дозволяє обробляти величезні кодові бази без розбиття на частини, а нові правила безпеки захищають від випадкових витоку даних. ⚒️ Як спробувати: Оновіть інструмент до версії v2.1.257, щоб автоматично отримати доступ до нової моделі та покращених налаштувань безпеки. 🔗 Джерело: Claude Code (releases) 📲 Ще новини AI українською
