NVIDIA випустила NOOA: агент у одному Python-класі

08.08.2026 09:00

NVIDIA Labs open-sourced NOOA — модельно-агностичний фреймворк для AI-агентів, який об'єднує промпти, інструменти та воркфлоу в єдиний клас. ⚡ Методи стають діями моделі, поля зберігають стан, а docstringи працюють як промпти. 🧩 Платформа вимагає лише Python 3.12–3.13 і підтримує будь-який LLM через LiteLLM. 💡 Чому це важливо: Замість розростання графів і callbacks, NOOA дозволяє тестувати, рефакторити та версіонувати агенти як звичайний код. 📈 На SWE-bench Verified та CyberGym показники сягають ~85% при використанні вдвічі менше токенів. ⚒️ Як спробувати: Встановіть через `pip install nooa` або завантажте з GitHub. Почніть з CodeActStrategy для ітеративного виконання коду, але пам'ятайте: для безпеки потрібен контейнер або VM. 🔗 Джерело: MarkTechPost
