Lossless-кодек для повідомлень AI-агентів зрізає 36% токенів

13.08.2026 13:00

Розробники представили a2acompress — безвтратний формат для передачі даних між AI-агентами. 📉 На реальних траєкторіях ToolBench він заощаджує 36,6% токенів, враховуючи витрати на декодування та словники. ⚡ Замість звичайного JSON використовує стислу схему, внутрішні посилання та сплайсинг, що значно розвантажує контекстне вікно мультиагентних пайплайнів. 💡 Чому це важливо: Мультиагентні системи часто "їдять" контекст на дублювання структур. 🧩 Безвтратний формат з чіткою угодою між агентами обходиться в інференсі дешевше, ніж звичайна стиснення або верbatim-передача JSON. ⚒️ Як спробувати: Встановіть через pip install -e . та запустіть оптимізацію на датасеті ToolBench. 💻 Готовий Python API дозволяє кодувати та декодувати сесії за лічені рядки, повністю зберігаючи байт-точну відповідність. 🔗 Джерело: GitHub 📲 Ще новини AI українською
