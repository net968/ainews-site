DeepSeek Harness v0.2: офіційні десктоп-додатки для macOS і Windows

04.10.2026 11:00

DeepSeek випустила офіційні клієнти для macOS та Windows для свого open-source інструменту DeepSeek Harness v0.2. 🚀 Нова версія під ліцензією MIT отримала менеджер плагінів, перегляд змін у файлах і коді, а також розкладовані автоматизації. ⚡ Система працює не лише з моделями DeepSeek, а й через OpenAI-сумісні API. 💡 Чому це важливо: Це перший крок від термінальних скриптів до зручного GUI для agent-робіт — поріг входу для не-девелоперів різко падає. ⚒️ Як спробувати: Завантажте додаток для своєї ОС та підключіть будь-яку модель через OpenAI-сумісний endpoint — починайте з простих Automation Tasks. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
