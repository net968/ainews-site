Cloudflare випустила Clef: моделі, що повертають ймовірності, а не текст

02.10.2026 17:00

Cloudflare представила Clef (27B) та Clef-flash (9B) — відкриті моделі для прийняття рішень. ⚡ Замість вільного тексту вони повертають типізовані ймовірності для заздалегідь визначених питань. Моделі вже доступні на Workers AI з медіанною затримкою 209.3 ms та 38.8 ms. 📊 Ваги завантажені на Hugging Face під ліцензією Apache 2.0, а API сумісне з TypeSafe AI Jev. 💡 Чому це важливо: Це змінює підхід до інтеграції AI: замість парсингу тексту ви отримуєте чисті дані, що спрощує автоматизацію та знижує ризки помилок у бізнес-логіці. ⚒️ Як спробувати: Завантажте ваги з Hugging Face для self-hosting або одразу викличте модель через Workers AI, щоб перевірити швидкість на своїх задачах. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
