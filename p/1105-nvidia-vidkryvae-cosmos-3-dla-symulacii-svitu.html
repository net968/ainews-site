NVIDIA відкриває Cosmos 3 для симуляції світу

06.11.2026 13:00

NVIDIA додала чотири нові open-weight моделі до платформи Cosmos 3 для генерації інтерактивних симуляцій. 📸 Вони створюють синхронізовані дані з камер та LiDAR для автономного водіння та роботів, враховуючи погоду, освітлення та дії.
