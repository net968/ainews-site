Redakto: інкогніто-вкладка для LLM

21.08.2026 09:00

Дослідники представили Redakto — open-source інструмент, який видаляє PII з тексту перед тим, як він потрапляє в LLM. 🧩 Є веб-інтерфейс для користувачів, REST API та MCP-хуки для розробників. 💡 Чому це важливо: Це прямий відповідь на вимоги ЄС щодо конфіденційності: можна використовувати LLM на реальних даних, не ризикуючи порушити правила. 🎯 Що це означає на практиці: Якщо ви працюєте з медичними чи юридичними документами — Redakto — це практичний шар захисту, який можна підключити до пайплайну вже зараз. 🔗 Джерело: arXiv cs.AI 📲 Ще новини AI українською
