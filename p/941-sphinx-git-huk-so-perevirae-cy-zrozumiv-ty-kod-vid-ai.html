Sphinx: Git-хук, що перевіряє, чи зрозумів ти код від AI

18.10.2026 11:00

Безкоштовний FOSS-інструмент Sphinx інтегрується у ваш workflow з AI-агентами (Codex, Claude Code, Cursor) та блокує push у прод, поки ви не відповісте на питання про логіку змін. 🧩 Система аналізує диф, ставить сценарні запитання про обробку помилок, а якщо ви помиляєтесь — пояснює і дає спробувати ще раз. 💡 Чому це важливо: Це перший крок до відповідального vibecoding: ви делегуєте написання коду, але залишаєте за собою розуміння того, що відбувається під капотом. ⚒️ Як спробувати: Завантажте пакет через npm (npm install -g sphinx-understand) та запустіть sphinx install у своєму репозиторії. Інструмент працює на Node 22.19+ та сумісний з OpenRouter чи будь-яким OpenAI-компатиблним API. 🔗 Джерело: Hacker News: AI 📲 Ще новини AI українською
