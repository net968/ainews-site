VS Code 1.136: Agent Merge автоматизує фіналізацію PR

05.09.2026 15:00

Microsoft випустила оновлення VS Code 1.136 з новою функцією Agent Merge. ⚡ Агент самостійно обробляє фідбек, виправляє конфлікти та провалині тести, поки pull request не буде готовий до злиття. 💡 Чому це важливо: Це знімає з розробників рутинну "біг-фікс-merge" петлю, дозволяючи фокусуватися на логіці, а не на CI/CD дрібницях. ⚒️ Як спробувати: Завантажте оновлення з code.visualstudio.com та увімкніть налаштування chat.agentMerge.enabled 👀. 🔗 Джерело: InfoWorld AI 📲 Ще новини AI українською
