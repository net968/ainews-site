Conduct: open-source контроль за діями AI-агентів

29.08.2026 09:00

Розробники представили Conduct — платформу для управління LLM, shell та MCP викликами. 🧩 Система працює за принципом "policy-first": блокування чи попередження відбуваються до виконання дії, а не після (як у runtime-файрволах). Аудит трек базується на SHA-256 хеш-ланцюгах та підписаних конфігураціях, що робить його незмінним для комплаєнсу. 💡 Чому це важливо: Поки більшість інструментів лише фіксують помилки постфактум, Conduct задає стандарти превентивного контролю, який обов'язковий для серйозного використання агентів у продакшн-середовищі. ⚒️ Як спробувати: Інструмент доступний зараз: встановіть CLI командою `pip install conduct-cli` або розгорніть локально через Docker з репозиторію GitHub. Є безкоштовний Discovery mode на 14 днів для спостереження без налаштування політик. 🔗 Джерело: Hacker News 📲 Ще новини AI українською
