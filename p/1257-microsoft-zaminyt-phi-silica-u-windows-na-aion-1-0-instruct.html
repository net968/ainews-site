Microsoft замінить Phi Silica у Windows на Aion 1.0 Instruct

26.11.2026 21:00

Нова локальна модель має 2,3 млрд параметрів проти 3,8 млрд у Phi Silica, а контекст зріс із 3,5 тис. до 32 тис. токенів 📈 Крім Copilot+ PC, вона підтримує окремі GPU AMD та Nvidia. Спершу заміна прийде в Windows Insider, а загальний реліз обіцяють до кінця січня 2027. 💡 Чому це важливо: Локальний AI без плати за токени стане доступним ширшому колу ПК. На Phi Silica спираються функції Windows і сторонній код. ⚒️ Як спробувати: API вже є в developer preview: візьміть демо на GitHub (потрібен .NET 9) або пакет із NuGet.
