Open WebUI 0.13: вкладки, Git і "комп'ютерний" режим

03.11.2026 17:00

Свіжий реліз Open WebUI v0.13.0 перетворює чат на повноцінний робочий простір 📑. З’явилися вкладки для файлів, терміналів і браузерних сесій, а також інтеграція Git прямо в бічну панель. 💡 Чому це важливо: Інструмент перестає бути просто інтерфейсом для AI і стає середовищем, де можна писати код, тестувати веб-застосунки та керувати "комп’ютером" моделі без переходів між окнами. ⚒️ Як спробувати: Оновіть локальну інсталяцію до версії 0.13.0 з GitHub та перевірте нові вкладки у верхньому меню чату 👀. 🔗 Джерело: Open WebUI (releases) 📲 Ще новини AI українською
