Claude Code вмикає Auto Mode за замовчуванням для захисту розробників

08.08.2026 19:07

З 14 серпня Anthropic активує Auto Mode у Claude Code для планів Pro, Max і Team. ⚡ Штучний інтелект виконуватиме дії самостійно, а вбудований класифікатор блокуватиме небезпечні команди — у тестах він впорався з 89% критичних операцій проти лише 13,6% у людей. Автономні команди отримали на 25% більше pull requests. 💡 Чому це важливо: Розробники поступово трансформуються з кодерів на ролі рецензентів AI-випадків 🎯. Автономність швидшає, але складність проектів змушує уважніше перевіряти висновки машини, особливо для критичної інфраструктури. ⚒️ Як спробувати: Оновіть Claude Code на будь-якому платному тарифі — функція активована автоматично. Запустіть рефакторинг у своєму репозиторії й подивіться, як класифікатор вирішує, чи запитувати підтвердження. 🔗 Джерело: The Decoder
