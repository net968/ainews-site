ToolJet 4.0: vibe-coding внутрішніх інструментів із контролем доступу

19.11.2026 19:01

Платформа ToolJet перебудувала конструктор застосунків: тепер фронтенд — це React-код, який можна згенерувати через Claude Code, Codex, Cursor, власного агента ToolJet або написати вручну. ⚡ Фронтенд не звертається до API чи баз напряму: усі запити йдуть через бекенд із контролем доступу, а інтеграцій із джерелами даних понад 100. 💡 Чому це важливо: Vibe-coding внутрішніх тулзів часто впирається в безпеку 🧩 — тут код скануватиметься перед збереженням, а ще є SSO, RBAC, версії, середовища та рев'ю перед продом. ⚒️ Як спробувати: Старт безкоштовний і без кредитної картки; код проєкту є на GitHub 👀.
