GitHub запускає HydraFusion: оркестрація моделей для коду

05.09.2026 07:00

GitHub представила Project HydraFusion — дослідницький прев'ю в Copilot, яке автоматично обирає найкращі моделі для кожної задачі. ⚡ Система створює план виконання, використовуючи стратегії Single, Cascade або Critique, щоб балансувати якість, вартість і швидкість. 💡 Чому це важливо: Це полегшує життя розробникам: вам не треба вручну перемикати моделі чи платити за дорогої інференси там, де вистачить дешевшої. 📈 На TerminalBench 2.1 рішення показало якість рівня Claude Opus 5, але за 67% нижчих витрат. 🎯 Що це означає на практиці: Якщо ви в GitHub Copilot, спробуйте переключитися на HydraFusion для складних репозиторіюм-задач. Це не просто "auto-select", а справжня оптимізація, яка економить бюджет без втрати якості. 👀 🔗 Джерело: GitHub Blog 📲 Ще новини AI українською
