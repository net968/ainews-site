Claude Code тепер підтримує AGENTS.md

19.09.2026 07:00

Anthropic додала підтримку стандарту AGENTS.md у версії 2.1.277. ⚡ Якщо у папці немає CLAUDE.md, Claude автоматично знайде та використає AGENTS.md. Функцію можна вимкнути через /config. 💡 Чому це важливо: Це полегшує міграцію між різними AI-агентами та об'єднує інструкції для проєктів в одному універсальному форматі. 🧩 ⚒️ Як спробувати: Оновіть Claude Code до версії 2.1.277 та додайте файл AGENTS.md в корені вашого репозиторію. Деталі реалізації можна переглянути в репозиторії Anthropic. 🔗 Джерело: Hacker News: Claude 📲 Ще новини AI українською
