Grok 4.6 від xAI тепер доступний в Amazon Bedrock

22.09.2026 07:00

xAI інтегрувала свій флагман Grok 4.6 у платформу Amazon Bedrock, зробивши його доступним для розробників. 📈 Модель має контекст на 500K токенів та чотири рівні глибини міркувань (від low до xhigh). Вона орієнтована на тривалі агентні сесії, складне кодування та роботу з великими обсягами даних. 💡 Чому це важливо: Поєднання потужної моделі xAI з інфраструктурою AWS спрощує інтеграцію в корпоративні пайплайни та дає гнучкість через підтримку Converse API та крос-регіонального інференсу. ⚒️ Як спробувати: Модель вже активна в каталозі Amazon Bedrock на ендпоінтах bedrock-mantle та bedrock-runtime. Перевірте документацію AWS і надішліть перший запит через Converse API або Chat Completions. 👀 🔗 Джерело: AWS Machine Learning 📲 Ще новини AI українською
