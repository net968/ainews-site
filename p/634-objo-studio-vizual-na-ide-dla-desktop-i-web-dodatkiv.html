Objo Studio: візуальна IDE для desktop і web додатків

13.09.2026 07:01

Розробник представив оновлення Objo Studio — сучасної візуальної RAD-IDE, натхненої класикою на кшталт Visual Basic та Delphi. ⚡ Тепер середовище дозволяє створювати застосунки для macOS, Windows, Linux та вебу з одного проєкту. Інструмент має власну об'єктно-орієнтовану мову з BASIC-синтаксисом та опційну інтеграцію з LLM-асистентами прямо в IDE. 🧩 Завантаження, компіляція та запуск мають бути миттєвими завдяки власній віртуальній машині на .NET. 💡 Чому це важливо: Повернення до візуального програмування з простим синтаксисом ідеально підходить для швидкого прототипування внутрішніх інструментів та дашбордів без складних фреймворків. ⚒️ Як спробувати: Середовище вже доступно — завітайте на сайт Objo, щоб завантажити IDE та створити свій перший візуальний застосунок. 🔗 Джерело: Hacker News: Vibe Coding 📲 Ще новини AI українською
