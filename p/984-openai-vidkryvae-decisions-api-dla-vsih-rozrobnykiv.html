OpenAI відкриває Decisions API для всіх розробників

23.10.2026 07:00

OpenAI зробила свою модель для прийняття рішень широко доступною, вийшовши на ринок швидких та дешевих AI-агентів. ⚡ Замість окремої моделі компанія переформулювала ChatGPT Luna, скоротивши час відповіді з 1–3 секунд до 100–180 мс. 💡 Чому це важливо: Це прямий виклик TypeSafe та його моделі Jev, яка зробила стартап компанією з оцінкою $7.6 млрд. Швидкі "малі" моделі починають витісняти повноцінні LLM у робочих процесах, де критична швидкість і вартість. 🎯 Що це означає на практиці: Не поспішайте міняти інфраструктуру: бенчмарки показують, що OpenAI поки поступається Jev та Liquid D1 Ultra. Варто протестувати Decisions API на власних задачах, особливо якщо потрібна мультимодальність (обробка зображень), де Luna виглядає сильніше. 🔗 Джерело: TechCrunch AI 📲 Ще новини AI українською
