Cloudflare запускає гаманці для ШІ-агентів

05.08.2026 15:00

Cloudflare анонсувала систему ідентифікаторів cloudflare.pay та програмовані криптогаманці для ШІ-агентів. ⚡ Агенти зможуть самостійно оплачувати API, дані та онлайн-сервіси через мікроплатежі за протоколом x402, не чекаючи ручного підтвердження. Користувачі вже можуть зарезервувати унікальну адресу, хоча повноцінні гаманці запустять пізніше. 💡 Чому це важливо: Агентна економіка потребує безшовних мікроплатежів 💸 — без цього ШІ-боти зможуть лише «читати» веб, але не зможуть самостійно купувати доступ до платних API чи даних. 🎯 Що це означає на практиці: Запасайтеся cloudflare.pay-адресами вже зараз — вони стануть візитівкою ваших агентів. ⚖️ Пильнуйте ліміти та списки дозволеных продавців, щоб уникнути витоків бюджету, поки повноцінні гаманці ще готуються до релізу. 🔗 Джерело: Mezha.Media
