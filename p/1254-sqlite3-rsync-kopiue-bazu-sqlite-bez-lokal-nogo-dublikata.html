sqlite3_rsync копіює базу SQLite без локального дубліката

26.11.2026 13:01

Саймон Віллісон звернув увагу на цінну рису sqlite3_rsync: він передає знімок бази через SSH на іншу машину без повної локальної копії. 🧩 Backup API та VACUUM INTO потребують місця під дублікат. Інструмент також синхронізує наявну репліку, не пересилаючи всю базу: за хешами сторінок визначає відмінності. Якщо копії дуже різні, трафік може перевищити розмір бази, але щонайбільше на кілька відсотків. 💡 Чому це важливо: Якщо на невеликому сервері база займає понад половину диска, місця для повної копії не вистачить. ⚡ Тут вона не потрібна. ⚒️ Як спробувати: Почніть з документації sqlite3_rsync на сайті SQLite та тестової бази з копією на іншій машині через SSH. Інструмент з'явився у SQLite 3.47.0 як експериментальний, а у 3.50.0 його покращили. 🔗 Джерело: Simon Willison 📲 Ще новини AI українською
