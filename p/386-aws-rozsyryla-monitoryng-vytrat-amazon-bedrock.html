AWS розширила моніторинг витрат Amazon Bedrock

13.08.2026 09:00

Оновлення CUR 2.0 для Amazon Bedrock тепер автоматично фіксує кожен запит інференсу через IAM principal. ⚙️ Це дає точну атрибуцію витрат по користувачах, проектах і командах: агрегуйте дані через SQL у Athena або відображайте їх у дашбордах CUDOS. Зверніть увагу — увімкнення caller identity збільшує обсяг файлів, тому плануйте S3 Lifecycle. 💡 Чому це важливо: Без детальної атрибуції AI витрати розмиваються в загальному ліміті 💸 — новий підхід дозволяє точно chargeback між командами та швидко ідентифікувати найдорожчі пайплайни. ⚒️ Як спробувати: Клонуйте репозиторій з налаштуванням, увімкніть опцію Include caller identity у CUR 2.0 та запустіть SQL-запити до Athena.
