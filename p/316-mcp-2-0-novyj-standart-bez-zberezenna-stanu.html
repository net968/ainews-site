MCP 2.0: новий стандарт без збереження стану

01.08.2026 11:00

Специфікація MCP 2.0 кардинально змінює підхід до протоколу Model Context Protocol. Тепер замість двох HTTP-запитів використовується лише один, що значно спрощує реалізацію серверів та клієнтів. ⚡️ Це робить систему безпечнішою та набагато зручнішою для масштабування вебдодатків. 💡 Чому це важливо: Перехід на stateless-режим прибирає складність підтримання сесій на боці сервера. 🧩 Це дозволяє навіть невеликим моделям ефективніше керувати інструментами без зайвого ризику. ⚒️ Як спробувати: Ви можете протестувати протокол через новий CLI-інструмент mcp-explorer за допомогою команди `uvx mcp-explorer list [URL]` 👀. 🔗 Джерело: Simon Willison
