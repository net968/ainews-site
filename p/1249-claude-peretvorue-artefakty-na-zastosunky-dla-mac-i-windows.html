Claude перетворює артефакти на застосунки для Mac і Windows

25.11.2026 21:00

Anthropic почала бета-розгортання функції Install as app на всіх планах. 🧩 Артефакт отримує власну іконку та вікно, може звертатися до Claude і ваших конекторів та оновлюється після редагувань. API-ключ не потрібен, а запити враховуються в лімітах плану. 💡 Чому це важливо: Власний інструмент можна встановити без пакування й підпису. Але з повним доступом ⚡ застосунок запускає програми, читає, змінює й видаляє файли, не питаючи щоразу. ⚒️ Як спробувати: У Claude для Mac чи Windows встановіть свій артефакт через Install as app (не з шаблонів; на Enterprise функцію вмикає власник).
