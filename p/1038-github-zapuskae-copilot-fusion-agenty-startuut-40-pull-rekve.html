GitHub запускає Copilot Fusion: агенти стартують 40% пулл-реквестів

28.10.2026 23:01

На GitHub Universe представили Copilot Fusion — систему, яка автоматично обирає найкращу AI-модель для кожного кроку коду. ⚡ За даними Microsoft, вона працює на 40% швидше та на 77% дешевше від конкурентів, зберігаючи високу якість. 💡 Чому це важливо: AI-агенти стають повноцінними співробітниками: вже понад 40% пулл-реквестів на GitHub починаються з чернеток від агентів, а не людей. 📈 🎯 Що це означає на практиці: Для Enterprise-користувачів це означає, що всі функції Copilot тепер доступні без окремої підписки — оплата лише за використані кредити.
