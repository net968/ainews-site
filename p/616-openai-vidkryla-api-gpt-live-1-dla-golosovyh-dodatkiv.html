OpenAI відкрила API GPT-Live-1 для голосових додатків

11.09.2026 07:00

OpenAI запустила GPT-Live-1 як доступний API, який дозволяє додаткам говорити та слухати одночасно (full-duplex). ⚡ Модель показує 80.1% в тестах інтерактивності проти 45.4% попередника, а затримка відповіді впала до 0.8 с. Ціна — $0.05 за хвилину, інструмент уже працює в ChatGPT. 💡 Чому це важливо: Голосові інтерфейси стають повноцінними альтернативами текстовим, що змінює підхід до створення клієнтського сервісу та асистентів. ⚒️ Як спробувати: Інструмент доступний через API OpenAI — перегляньте документацію, щоб підключити модель до ваших проєктів та протестувати 12 нових голосів. 🔗 Джерело: The Decoder 📲 Ще новини AI українською
