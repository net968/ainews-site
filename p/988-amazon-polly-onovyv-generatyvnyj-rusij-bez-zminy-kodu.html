Amazon Polly оновив генеративний рушій без зміни коду

23.10.2026 15:00

AWS представила потужне оновлення Amazon Polly для синтезу мовлення: голоси стали виразнішими та точнішими, а затримки — мінімальними. ⚡ Додали 14 нових голосів у 9 локалях, а хінді та фінська мови стали загальнодоступними. 💡 Чому це важливо: Це drop-in оновлення: API та назви голосів не змінились, тож існуючі застосунки одразу отримають якість нового рівня без переписування коду. ⚒️ Як спробувати: Перевірте різницю на демо-аудіо в блозі AWS 👀, а потім просто оновіть існуючі запити до API — нові можливості з'являться автоматично в 11 регіонах. 🔗 Джерело: AWS Machine Learning 📲 Ще новини AI українською
