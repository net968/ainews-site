Nari Labs робить open-source голос швидшим за ElevenLabs

15.09.2026 13:01

Команда Nari Labs випустила спеціалізований інференс-движок для моделей Qwen3-TTS та Qwen3-ASR. ⚡ Завдяки оптимізації їхні ендпоінти зайняли верхні позиції в бенчмарках Coval: TTS показав найкращу точність (WER 3.8%) при затримці 63 мс, а ASR — найнижчу затримку (44 мс). 💡 Чому це важливо: Голосові AI-агенти вимагають миттєвої реакції. Nari Labs доводить, що відкриті моделі можуть конкурувати з платними сервісами за якістю, будучи при цьому в 5-6 разів дешевшими. ⚒️ Як спробувати: Код інференс-движка відкрито доступний у GitHub 📂, а для тестування API можна зареєструватись на сайті Nari Labs — компанія обіцяє $20 кредитів при переході на платний тариф. 🔗 Джерело: Hacker News: AI 📲 Ще новини AI українською
