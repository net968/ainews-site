Claude Code навчив сесії обмінюватися контекстом

08.08.2026 17:07

Anthropic оновив Claude Code, тепер паралельні сесії на macOS та Linux можуть надсилати повідомлення, ділитися інсайтами та перевіряти статус одна одної. ⚡ Замість ручного копіювання AI самостійно передає дані або запитує відповіді між терміналами. Функція працює локально на одному пристрої та через сервери Anthropic на віддалених машинах, але поки не підтримується в Bedrock, Google Cloud Agent Platform чи Microsoft Foundry. 💡 Чому це важливо: Мультиагентні пайплайни та координування паралельних задач стануть значно простішими — не треба писати складний шар синхронізації, достатньо дозволити сесіям «балакати». 🧩 ⚒️ Як спробувати: Оновіть клієнт Claude Code на macOS або Linux, відкрийте кілька терміналів і перевірте в налаштуваннях увімкнення обміну повідомленнями між сесіями. 👀 🔗 Джерело: The Decoder
