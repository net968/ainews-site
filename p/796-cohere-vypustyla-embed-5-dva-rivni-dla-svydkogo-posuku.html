Cohere випустила Embed 5: два рівні для швидкого пошуку

01.10.2026 23:00

Cohere представила сімейство моделей Embed 5 для enterprise-пошуку та RAG. 🧩 Воно складається з двох рівнів: Pro для максимальної якості та Fast для низької затримки в агентах. Обидва працюють у спільному просторі, тож можна індексувати даними Pro, а запити робити через Fast. 💡 Чому це важливо: Fast обробляє 377 документів/сек проти 159 у Pro, що критично для агентів, які роблять десятки запитів. 📈 А вартість стартує від $0.08 за 1 млн токенів. ⚒️ Як спробувати: Модель вже доступна в API Cohere, Microsoft Foundry та Amazon SageMaker. Почніть із embed-v5.0-fast для живих запитів — це дозволить зекономити на затримках без втрати точності. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
