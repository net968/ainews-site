Supabase випустила Evals для тестування AI-агентів

01.08.2026 15:01

Supabase зробила відкритим фреймворк Supabase Evals, який оцінює кодинг-агентів (наприклад, Claude Code або Codex) на реальних задачах. ⚡️ Система тестує здатність AI будувати схеми, дебажити Edge Functions та виправляти політики RLS у справжніх контейнеризованих середовищах. 💡 Чому це важливо: Тести проходять у реальному стеку, а не на моках, що дозволяє об'єктивно порівняти агентів та виявити їхні слабкі місця в роботі з безпекою й архітектурою. 🧩 🛠 Як спробувати: Фреймворк доступний на GitHub — його можна запустити локально через pnpm, маючи Docker та API-ключі провайдера. 👀 🔗 Джерело: MarkTechPost
