DeepSeek відкрила код інференс-рушія DeepInfer

20.10.2026 15:00

Команда DeepSeek опублікувала DeepInfer — високопродуктивний інференс-фреймворк, який забезпечує роботу їхніх великомасштабних продуктивних сервісів. 🧩 Реліз підтримує модель DeepSeek-V4.1-Flash та працює на NVIDIA SM100 GPU та Huawei Ascend 950 NPU. 💡 Чому це важливо: Відкриття внутрішніх інструментів показує, як реальні інженери оптимізують швидкість генерації, що дає спільноті потужний інструмент для самостійного розгортання моделей. ⚒️ Як спробувати: Завантажте репозиторій GitHub та створіть Python 3.12 середовище. Для запуску потрібні Linux, GCC 13.0+ та CUDA 13 (або CANN 9.2 для Ascend) — почніть із прикладу offline_inference.py. 🔗 Джерело: Hacker News: AI 📲 Ще новини AI українською
