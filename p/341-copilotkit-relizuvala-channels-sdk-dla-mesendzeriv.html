CopilotKit релізувала Channels SDK для месенджерів

05.08.2026 11:00

CopilotKit випустила опенсорсну бібліотеку Channels SDK (ліцензія MIT), щоб запускати AI-агентів у Slack та Microsoft Teams. ⚡ Версія 0.5.0 підтримує протокол AG-UI, тому ваші агенти на базі LangGraph, CrewAI чи Pydantic AI працюватимуть без переписування коду. Система сама транслює інтерфейси (JSX) у рідні формати платформ, як-от Block Kit або Adaptive Cards. 🧩 💡 Чому це важливо: Тепер можна масштабувати AI-інструменти на корпоративні чати без зайвого клопоту з адаптацією UI під кожне окреме вікно. ⚒️ Як спробувати: Встановлюйте пакети @copilotkit/channels та @copilotkit/runtime через npm або перегляньте документацію на GitHub. 👀 🔗 Джерело: MarkTechPost
