0sec Labs відкрила код AI-інструмента для безпеки коду

09.11.2026 15:00

Компанія 0sec Labs опублікувала open-source проєкт 0 — AI-гарнітуру для рецензування коду, пентестингу та реверс-інжинірингу. ⚡ Інструмент працює локально через веб-інтерфейс, CLI або MCP-сервер, дозволяючи використовувати власного провайдера моделей. 💡 Чому це важливо: Безпека коду стає доступнішою: розробники можуть автоматизувати пошук вразливостей без залежності від хмарних сервісів та без передачі даних третім сторонам. ⚒️ Як спробувати: Знайдіть репозиторій 0sec Labs на GitHub, клонуйте його та запустіть локально через CLI чи браузер — налаштуйте підключення до свого AI-провайдера й проженіть перший аудит коду. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
