OpenAI GPT-6.1 та GPT-6 тепер доступні з Канади через AWS Bedrock

21.10.2026 11:01

Канадські компанії можуть залучати моделі GPT-5.6, GPT-6 та GPT-6.1 безпосередньо з регіонів Canada (Central) і Canada West (Calgary). ⚡ Функція cross-Region inference автоматично маршрутизує запити в Північній Америці, зберігаючи дані локально та розширюючи пул потужностей. 💡 Чому це важливо: Це закриває критичний дефіцит найсвіжіших моделей OpenAI для північноамериканського ринку, дозволяючи зберігатися в межах вимог до даних без втрати продуктивності. ⚒️ Як спробувати: Налаштуйте inference profile з префіксом us. у вашому AWS-акаунті та інтегруйте запити через OpenAI Responses API або Bedrock Converse API — почніть із прикладів у репозиторії AWS. 🔗 Джерело: AWS Machine Learning 📲 Ще новини AI українською
