Gamma PDF — open-source рідер PDF з AI для наукових статей

14.11.2026 17:00

Gamma PDF — self-hosted застосунок, що об'єднує PDF, нотатки й AI-чат в одному місці. Статтю відкриваєш за посиланням на arXiv чи DOI, виділене речення стає нотаткою з посиланням на сторінку, а AI відповідає з клікабельними цитатами. 📚 Є імпорт із Zotero, Obsidian, Logseq і Notion, а також підтримка Apple Pencil на iPad. 💡 Чому це важливо: Замість зв'язки Zotero + Obsidian + вкладка з чатом — один інструмент, де дані лежать у вашій папці (SQLite і файли), без акаунта й телеметрії. 🔒 ⚒️ Як спробувати: Запустіть через Docker одним командним рядком із інструкції на GitHub (порт 9001) або завантажте останній реліз. Для AI потрібен власний ключ Anthropic чи OpenAI або платний план ChatGPT; Codex і Claude Code підключаються через MCP. 🧩 🔗 Джерело: Hacker News 📲 Ще новини AI українською
