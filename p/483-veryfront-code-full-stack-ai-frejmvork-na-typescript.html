Veryfront Code: full-stack AI-фреймворк на TypeScript

26.08.2026 23:00

З'явився Veryfront Code — відкритий open-source фреймворк для побудови AI-агентів та React-додатків у єдиному TypeScript-проєкті. 🧩 Він об'єднує маршрути, агенти, інструменти та evals в одному файлоорієнтованому середовищі, працюючи на Node.js, Deno або Bun. Розробники та coding-агенти працюють з джерелом за одними й тими ж конвенціями, а інференс можна підключити напряму до провайдерів або локальних сервісів. 💡 Чому це важливо: Зменшує хаос у стеках, де логіка агентів, UI та інструменти розкидані по різних репозиторіях та мовах. ⚒️ Як спробувати: Код вже на GitHub. Створіть проєкт командою npm create veryfront@latest my-agent та запустіть npm run dev з встановленим OPENAI_API_KEY. 🔗 Джерело: Hacker News: AI 📲 Ще новини AI українською
