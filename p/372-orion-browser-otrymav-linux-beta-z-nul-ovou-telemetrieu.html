Orion Browser отримав Linux-бета з нульовою телеметрією

10.08.2026 21:01

Розробники Orion Browser представили бета-версію для Linux — швидкого браузера з нульовою телеметрією та вбудованим блоком реклами. 📈 Цей реліз стабільніший за попередній, додає локальну синхронізацію, режим економії заряду та повноцінну підтримку розширень. ⚡ Доступний безкоштовно на macOS, iOS, iPadOS, версія для Windows з'явиться найближчим часом. 💡 Чому це важливо: Zero-telemetry підхід поєднується з нативною підтримкою розширень та швидкістю на рівні Safari, що створює ринкову нішу для приватних альтернатив без жорсткої прив'язки до екосистеми Apple. ⚒️ Як спробувати: Завантажте бета-версію з офіційного сайту Orion Browser для Linux, macOS чи iOS. Для глибокої кастомізації інтерфейсу зверніться до репозиторію на GitHub 🛠 🔗 Джерело: ZDNet AI
