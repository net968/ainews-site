Кодінг-агенти тепер керують Blender на macOS

05.09.2026 21:00

Simon Willison демонструє, як сучасні LLM-агенти ефективно працюють з Blender через Python API. ⚡ Встановивши десктопну версію на Mac, ви можете просити агента рендерити 3D-сцени, генерувати .blend файли та навіть створювати відео через ffmpeg. У прикладі агент створив детальну анімацію пелікана на велосипеді за кількома ітеративними промптами. 💡 Чому це важливо: Це відкриває новий рівень автоматизації для 3D-контенту: агенти можуть самостійно писати скрипти, рендерити та ітерувати візуали без ручного моделювання. ⚒️ Як спробувати: Встановіть Blender з офіційного сайту та попросіть вашого кодинг-агента (наприклад, ChatGPT Codex) використати його Python API.
