DeepSeek випустила Vision-версію Flash для агентов

21.08.2026 15:00

На платформі DeepSeek API з’явилась експериментальна модель DeepSeek-V4-Flash-Vision-Exp. 🧠 Вона зберігає потужність тексту оригіналу (агенти, рендеринг), але додає здатність працювати з зображеннями. На бенчмарках мультимодальних агентів результат наблизився до Opus-4.8. 💡 Чому це важливо: Мультимодальність стає стандартом для AI-агентів ⚡ — тепер моделі можуть не лише читати текст, а й «бачити» інтерфейси чи скріншоти, щоб виконувати складніші задачі в реальному часі. ⚒️ Як спробувати: Підключайте нову модель через `model='deepseek-v4-flash-vision-exp'`. Використовуйте оновлений пакет DeepSeek Harness 0.1.1 для зручного старту 📁. Завантаження зображень через Files API безкоштовне, а тарифікація йде за токенами як у звичайному V4-Flash. 🔗 Джерело: DeepSeek AI (X) 📲 Ще новини AI українською
