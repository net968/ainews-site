Plugin4Shell: одна git-хитрість зламувала 4 AI-агенти

21.09.2026 19:00

Дослідники Air Security виявили вразливість, що дозволяє виконувати код від імені розробника без жодного кліку. ⚡ Атака працює через підміну гілки в git, обходячи захист версій плагінів. Падіння зачепило Claude Code, Codex, Gemini CLI та Copilot. 👀 💡 Чому це важливо: AI-агенти мають повний доступ до ваших файлів та креденшелів. Якщо механізм авто-оновлення плагінів не перевіряє реальний стан коду, ви відкриваєте двері для злодія в системі. 🎯 Що це означає на практиці: Оновіть Claude Code до версії 2.1.179 та Codex до 0.146.0. Для Copilot патчу немає — якщо використовуєте маркетплейси поза GitHub, перевірте безпеку своїх git-репозиторіїв самостійно. 🔗 Джерело: TNW 📲 Ще новини AI українською
