Grok Voice Transcribe 2.0: точність х2 за тією ж ціною

19.09.2026 11:01

xAI випустила нову модель розпізнавання мовлення Grok Voice Transcribe 2.0. ⚡ Вона вдвічі точніша за попередню версію та займає перше місце серед 32 стрімінгових моделей на лідерборді Artificial Analysis. Ціни не змінились: $0.10/год для батчу та $0.20/год для стрімінгу. 💡 Чому це важливо: Модель спеціально оптимізована для «брудного» аудіо: шум, акценти та перебивання. 🎯 Це критично для реальної комунікації, а не лише для чистих записів. ⚒️ Як спробувати: Сервіс вже доступний через Speech-to-Text API xAI.
