Amazon Textract Insights: generative AI для документів із перевіркою джерела

21.11.2026 07:01

AWS оголосила загальну доступність Amazon Textract Insights — нового API в Textract. Ви описуєте потрібні поля природною мовою, подаєте документ або змішаний пакет (до 3 000 сторінок), а у відповідь отримуєте структуровані дані. 📄 Кожне значення має confidence score і посилання на сторінку-джерело, навчання моделі не потрібне. 💡 Чому це важливо: Звичайні LLM дають гладкі відповіді без джерела й оцінки впевненості, тож незрозуміло, що приймати автоматично, а що перевіряти вручну. ✅ Тут цю прогалину закрито. ⚒️ Як спробувати: Почніть із публічного blueprint AWS (W-2, Form 1040, паспорт тощо) або опишіть власний у JSON Schema 🧩 і запустіть один асинхронний виклик StartDocumentInsights для файлу з вашого S3. Ціну у джерелі не вказано, тож перевірте її на сторінці Textract. 🔗 Джерело: AWS Machine Learning 📲 Ще новини AI українською
