DeepSeek випустила V4.1-Flash-1017 і відкрила Search API

17.10.2026 15:00

DeepSeek представила DeepSeek-V4.1-Flash-1017 — новий чекпойнт моделі V4.1-Flash. Він уже працює на сайті, в застосунку та через API. ⚡ Компанія заявляє про вищі результати, швидше виконання задач і коротші відповіді порівняно з вереснем, а результат на DeepSWE — 77.0. Паралельно відкрито Search API. 💡 Чому це важливо: DeepSeek називає оновлення Pareto-покращенням у продуктивності та вартості 📈 — тобто кращий результат без зростання ціни. ⚒️ Як спробувати: Модель вже доступна на сайті DeepSeek, у застосунку та через API — перемкніть свій тестовий пайплайн на V4.1-Flash-1017 і порівняйте з вересневою версією на власних задачах 👀. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
