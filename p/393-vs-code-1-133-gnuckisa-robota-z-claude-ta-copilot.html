VS Code 1.133: гнучкіша робота з Claude та Copilot

13.08.2026 23:01

Microsoft оновила VS Code до версії 1.133, де тепер можна змішувати провайдерів Anthropic API та GitHub Copilot у межах однієї сесії Claude ⚡. Перемикайте моделі між кроками без перезавантаження агента, а новий експериментальний параметр дозволяє відкривати вікно Agents без авторизації в GitHub 🔑. 💡 Чому це важливо: Міграція між платними API та підпискою Copilot більше не змушує переривати контекст сесії — розробники економлять час та оптимізують витрати на інференс 🧩. ⚒️ Як спробувати: Завантажте VS Code 1.133 з офіційного сайту, увімкніть chat.agentHost.allowSignedOutWhenUsable у налаштуваннях та перевірте picker моделей у чаті 👀. 🔗 Джерело: InfoWorld AI 📲 Ще новини AI українською
