Meta випустила Muse Code – конкурента Codex і Claude Code для великих проєктів

06.08.2026 11:19

Meta представила бета-версію Muse Code — ШІ-агента для кодування, який планує зміни, пише й перевіряє код у великих репозиторіях. ⚡ Система базується на моделі Muse Spark 1.2 та розподіляє завдання між паралельними субагентами в ізольованих гітках Git. У тесті агент виконав понад 1000 кроків за 24 години, оптимізуючи GPU-ядра. 💡 Чому це важливо: AI-інструменти переходять від автодоповнення до повноцінних розробників, здатних керувати складними проєктами паралельно. Мета позиціонує продукт як дешевшу альтернативу OpenAI та Anthropic. ⚒️ Як спробувати: Встановлюється однією командою на macOS або Linux 💻 — модель доступна й через Meta Model API. Запустіть /plan у терміналі, щоб побачити, як агент будує дерево завдань перед кодуванням. 🔗 Джерело: Mezha.Media
