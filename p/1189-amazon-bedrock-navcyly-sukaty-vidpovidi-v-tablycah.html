Amazon Bedrock навчили шукати відповіді в таблицях

16.11.2026 21:01

Managed Knowledge Base в Amazon Bedrock тепер підтримує tabular search: агентний пошук відповідає на питання за файлами CSV, XLSX і XLS. ⚡ Код в ізольованому sandbox читає оригінальний файл і рахує по кожному рядку, а потім поєднує результат з фактами з документів. Усе це через той самий запит AgenticRetrieveStream. 💡 Чому це важливо: Звичайний RAG ріже таблиці на уривки й бачить лише кілька рядків, тому суми та порівняння виходять неповними 📈. ⚒️ Як спробувати: Візьміть приклад на GitHub із фінансовими файлами 👀 і перегляньте trace, щоб побачити, який файл прочитав код. У запитанні краще прямо називати потрібну таблицю. 🔗 Джерело: AWS Machine Learning 📲 Ще новини AI українською
