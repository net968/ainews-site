Cursor видалив шкідливу розширення Claude Code з SSH-бекдором

02.11.2026 17:00

У маркетплейсі Cursor було знайдено змінений варіант розширення Claude Code, яке намагалося встановити постійний SSH-бекдор на комп'ютерах розробників. ⚡ Зловмисний код діяв протягом 11 годин на версіях 2.1.312 та 2.1.313, спробувавши додати ключ атакуючого та створити reverse tunnel. 💡 Чому це важливо: Це не просто баг, а спроба перехопити доступ до source code та credential'ів через інструмент, якому розробники довіряють щодня. 👀 🎯 Що це означає на практиці: Якщо ви оновлювали Cursor 29 жовтня, просто видалити розширення мало — перевірте authorized_keys та автозапуск на Windows/macOS, бо скрипти могли залишитися поза каталогом програми. 🔗 Джерело: InfoWorld AI 📲 Ще новини AI українською
