Qwen3.8-Omni-Flash: мультимодальний AI-агент за копійки

19.09.2026 21:00

Alibaba представила Qwen3.8-Omni-Flash — першу мультимодальну модель для AI-агентів, яка обробляє аудіо й відео та самостійно використовує інструменти. 🎬 На бенчмарках вона майже дорівнює Gemini 3.8 Flash, але коштує значно менше: $0.15 за мільйон токенів на вході проти $0.75 у Google. Контекстне вікно сягає 1 млн токенів. 💡 Чому це важливо: Зниження вартості обробки відео та аудіо робить створення складних мультимодальних агентів доступним для масового застосування, а не лише для великих корпорацій. ⚒️ Як спробувати: Модель доступна через Qwen Studio, Qwen Cloud та API. Для розширення функціоналу агентів завантажте Qwen-MM-Plugins на GitHub — там є готові рішення для відеомонтажу та розпізнавання мовлення. 🔗 Джерело: The Decoder 📲 Ще новини AI українською
