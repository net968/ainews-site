Ambient Context: текстовий лог активності для LLM

25.08.2026 11:12

Оновлення macOS menu bar-додаток, який читає текст активного вікна через Accessibility API та записує його у Markdown-файли. 📝 Без скріншотів, OCR чи відправки даних у хмару — усе лишається на вашому диску. Формат файлів оптимізований для LLM: є `AGENTS.md`, дедуплікація рядків та фільтрація секретів. 💡 Чому це важливо: Це простий спосіб створити «пам’ять» для Claude Code чи інших агентів, щоб вони розуміли контекст вашої роботи без складних інтеграцій. ⚒️ Як спробувати: Проєкт ще ранній і без підпису, тому доведеться збирати вручну: клонуйте репозиторій, встановіть Node, Rust та Xcode CLT, потім виконайте `npm run tauri build`. 🔗 Джерело: Hacker News: Claude 📲 Ще новини AI українською
