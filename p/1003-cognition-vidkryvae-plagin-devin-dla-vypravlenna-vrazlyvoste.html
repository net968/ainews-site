Cognition відкриває плагін Devin для виправлення вразливостей

25.10.2026 09:00

Компанія Cognition опублікувала MIT-ліцензований плагін Devin Vulnerability Fixes для AI-агентів. 🧩 Він складається з трьох навичок, які автоматично інвентаризують, латають та тестують вразливості RCE у PHP, Node.js та self-managed GitLab. Після виправлення агент відкриває окремий pull request для кожного репозиторію. 💡 Чому це важливо: Це перший крок до промислових AI-агентів, які не просто знаходять баги, а закривають цілі кіберзагрозні інциденти в реальних стеках. ⚒️ Як спробувати: Плагін відкритий — знайдіть репозиторій Cognition з набором агентських навичок та інтегруйте його у свій CI/CD для автоматичного моніторингу безпеки. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
