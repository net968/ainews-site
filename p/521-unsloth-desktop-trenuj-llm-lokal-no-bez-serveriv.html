Unsloth Desktop: тренуй LLM локально без серверів

31.08.2026 15:00

Двоє братів з Unsloth випустили Unsloth Desktop — відкриту (Apache) альтернативу LM Studio для Windows, macOS і Linux. ⚡ Це не просто хост для моделей, а повноцінний воркбенч: тут є генерация зображень, TTS та графічні воркфлоу "Data Recipes" у стилі ComfyUI. 💡 Чому це важливо: З'являється потужний інструмент для тих, хто хоче тренувати кастомні моделі на своєму залізі, не орендуючи дорогі GPU-клаути. ⚒️ Як спробувати: Завантажте додаток зі сторінки документації Unsloth.
