llama.cpp досяг версії v1.0.0

13.11.2026 19:00

Команда llama.cpp випустила v1.0.0 для бібліотек libllama та libggml (ggml v1.0.0). Відтепер несумісні зміни API й ABI позначатимуться підвищенням мажорної версії. 🧩 Проєкту 3,5 роки, він підтримує понад 150 архітектур моделей і поширюється через Docker, Homebrew, conda-forge, Winget та інші канали. 💡 Чому це важливо: Від llama.cpp залежить дедалі більше застосунків, тож стабільний API з чіткими правилами semver — це база для надійних локальних AI-продуктів ⚡ ⚒️ Як спробувати: Встановіть через Homebrew, Winget, conda-forge чи Docker, або візьміть код із GitHub 👀 Якщо будуєте на libllama, закріпіть мажорну версію у залежностях. 🔗 Джерело: Hugging Face Blog 📲 Ще новини AI українською
