Buoyant випустила Kinference для vLLM на Kubernetes

07.11.2026 15:00

Buoyant представила Kinference — open-source керуючу платформу з ліцензією Apache 2.0 для запуску vLLM у Kubernetes. ⚡ Інструмент додає декларативне маршрутизування, балансування на основі KV-cache та метрики для кожного орендаря. За бенчмарками Buoyant, медіана часу до першого току (TTFT) зменшилася на 95%. 💡 Чому це важливо: Ефективне управління ресурсами інференсу стає критичним для масштабування LLM-сервісів 💸 — Kinference пропонує готове рішення для оптимізації витрат та швидкодії. ⚒️ Як спробувати: Kinference доступна як open-source інструмент — почніть із налаштування маршрутизації для вашого кластера Kubernetes 👀. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
