Оновлення LLM 0.32: підтримка GPT-5.6 та треків мислення

05.08.2026 13:01

Simon Willison випустив масштабне оновлення утиліти LLM (v0.32). Тепер CLI підтримує відображення "мислення" моделей через reasoning traces та вбудовану підтримку сімейства GPT-5.6, зокрема моделі Luna. ⚡ Також додано підтримку серверних інструментів, як-от Code Interpreter від OpenAI. 💡 Чому це важливо: Це дозволяє бачити внутрішній процес роздумів моделі, не засмічуючи основний потік даних. 🧩 Такий підхід критично важливий для перевірки логіки складних запитів у режимі реального часу. ⚒️ Як спробувати: Оновіть утиліту та протестуйте нові функції за допомогою плагіна llm-anthropic, що тепер підтримує WebSearch та CodeExecution. 🔗 Джерело: Simon Willison
