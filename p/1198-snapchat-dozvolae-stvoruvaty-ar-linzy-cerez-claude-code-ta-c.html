Snapchat дозволяє створювати AR-лінзи через Claude Code та Cursor

19.11.2026 07:00

Компанія представила Easy Lens CLI, інструмент, що інтегрує створення AR-ефектів у робочі процеси розробників. ⚡ Тепер можна описати бажаний лінз простою мовою, а AI-асистенти, такі як Claude Code, Cursor чи Codex, самостійно напишуть код, згенерують ассети та опублікують результат. 💡 Чому це важливо: Snapchat знижує поріг входу в AR-розробку, перетягуючи на свою платформу мільйони розробників, які вже живуть у середовищі AI-кодінгу 📈. 🎯 Що це означає на практиці: Для маркетологів і креаторів це шанс швидко перетворити статичний контент на інтерактивний AR-досвід без найму спеціалістів. Якщо ви вже користуєтесь Cursor або Claude, варто поекспериментувати з тим, як ці інструменти генерують AR-об'єкти для ваших брендів 👀. 🔗 Джерело: TechCrunch AI 📲 Ще новини AI українською
