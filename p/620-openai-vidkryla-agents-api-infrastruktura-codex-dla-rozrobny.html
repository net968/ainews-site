OpenAI відкрила Agents API: інфраструктура Codex для розробників

11.09.2026 15:00

OpenAI запустила Agents API у публічній бета-версії. ⚡ Це дозволяє будувати хмарні агенти, які автономно працюють годинами, виконують код та делегують завдання суб-агентам. Система базується на тому ж інфраструктурному фундаменті, що й Codex та ChatGPT, підтримуючи паралельне використання інструментів та MCP. 💡 Чому це важливо: OpenAI дає доступ до промислової механіки своїх флагманів, дозволяючи створювати складні автоматизації без зайвих платежів — тарифікація йде виключно за токенів. ⚒️ Як спробувати: API вже доступно у публічній бета. Для старту варто поглянути на GitHub-репозиторій Codex, оскільки API будується на його open-source фундаменті, а для sandbox-середовищ можна обрати партнерів, наприклад Cloudflare чи Vercel. 🔗 Джерело: The Decoder 📲 Ще новини AI українською
