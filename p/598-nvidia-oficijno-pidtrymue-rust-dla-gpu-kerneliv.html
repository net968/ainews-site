NVIDIA офіційно підтримує Rust для GPU-кернелів

09.09.2026 07:01

NVIDIA анонсувала CUDA Rust — два open-source проєкти NVlabs, що роблять Rust першокласною мовою для GPU. cuda-oxide компілює SIMT-кернелі через Rust MIR, а cutile-rs — Tile-кернелі через JIT-компіляцію на стабільному Rust 1.89+. Обидва використовують правила володіння Rust для відлову помилок aliasing на етапі компіляції. ⚡ 💡 Чому це важливо: Rust вже активно заміняє C++ у системному шарі AI, і тепер це поширюється на самі GPU-кернелі — з безпекою пам'яті "з коробки". ⚒️ Як спробувати: cutile-rs вже на GitHub і працює на стабільному Rust — встановіть через cargo add cutile. cuda-oxide поки в ранній альфі, але доступний на GitHub для експериментів. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
