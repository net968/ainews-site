Bedrock 2.0: мінімалістичний стартер-кіт для Emacs

08.09.2026 09:01

Аштон випустив Bedrock 2.0 — легку конфігурацію для Emacs 31, яка працює без сторонніх пакетів у базі. 📝 Це просто два файли (init.el та early-init.el), які ви копіюєте в ~/.emacs.d/ та редагуєте вручну, без складних фреймворків. 💡 Чому це важливо: Для тих, хто хоче повноцінно володіти своєю конфігурацією, це ідеальний вхідний пункт: прозорий код, чіткі коментарі та жодного «магічного» автоматизованого апгрейду, що приховує суть. ⚒️ Як спробувати: Завантажте код зі сторінки автора та скопіюйте файли в ~/.emacs.d/. ⚡ Перевірте, чи стоїть у вас Emacs 31, або видаліть специфічні налаштування для цієї версії, якщо використовуєте старішу. 🔗 Джерело: Hacker News: LLM 📲 Ще новини AI українською
