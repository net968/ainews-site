Perplexity запустила Monitor API: вебпошук, що сам будить агентів

22.11.2026 19:00

Monitor API від Perplexity шукає в мережі за розкладом і надсилає webhook агентам лише коли з'являються релевантні зміни. ⚡ Є два режими: web monitors (пошук за запитом) і page monitors (до 10 сторінок, повертає текстовий diff). Власна decision-модель перевіряє релевантність, надійність джерела, новизну й актуальність; розклад — від 15 хвилин до тижня. 💡 Чому це важливо: Раніше команди самі писали код для повторних запитів, дедуплікації й пошуку змін — на сотнях тем це майже не масштабується 🧩 ⚒️ Як спробувати: API доступне вже зараз через API-консоль Perplexity з тим самим ключем, що й Search, Context та Agent API. Ціна: $1 за 1000 запитів.
