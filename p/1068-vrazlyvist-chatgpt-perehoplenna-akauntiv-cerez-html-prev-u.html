Вразливість ChatGPT: перехоплення акаунтів через HTML-прев'ю

01.11.2026 11:00

Parameter Labs знайшли складну ланцюжку атак у ChatGPT: шкідливий код в iframe міг вийти з песочниці через бібліотеку MathLive та вразливість innerHTML. ⚡ Зловмисники отримували повний доступ до приватних даних користувачів через спільні URL-посилання. 💡 Чому це важливо: Інцидент показує, наскільки критичним є ізолювання стороннього коду в AI-інтерфейсах — навіть "невидимі" бібліотеки можуть стати дверима для хакерів. 🎯 Що це означає на практиці: OpenAI вже закрила діру, але урок для всіх: не довіряйте автоматично виконуваному HTML у AI-чатах.
