Ollama v0.34.0: Open models now work in ChatGPT Desktop

06.09.2026 09:00

Ollama випустила версію v0.34.0 (pre-release), яка дозволяє використовувати локальні моделі прямо в ChatGPT Desktop 📱. Це дає змогу зберігати звичний воркфлоу, але працювати з відкритими моделями локально. 🛠 💡 Чому це важливо: Це мостить проміжок між приватними LLM та популярними інтерфейсами, дозволяючи розробникам і користувачам тестувати open-source моделі без зміни навичок чи додатків. ⚒️ Як спробувати: Оновіть застосунок Ollama на MacOS та налаштуйте інтеграцію через вбудований setup 👀.
