CadYam: безкоштовний десктопний дизайн-застосунок на Rust для роботи з AI-агентом

23.11.2026 21:00

CadYam — десктопна апка, де людина й AI-агент разом працюють над одним проєктом: CAD-кресленням, відео, планом інтер'єру чи аналізом даних. 🧩 Застосунок написаний на Rust і запускає локальний MCP-сервер, через який агент (наприклад, Claude чи Codex) користується тими самими командами, що й ви. Можна поставити «пін» у конкретному місці й попросити змінити саме його — правки з'являються як прев'ю. 💡 Чому це важливо: Класичні CAD-інструменти мають круту криву навчання, а тут складну роботу можна вести природною мовою — або попросити агента навчити вас користуватися апкою. ⚒️ Як спробувати: Завантажте застосунок для macOS, Windows чи Linux зі сторінки релізів на GitHub — зараз він безкоштовний ("for now") 👀.
