Microsoft оновила Copilot: кодинг для нон-техніків та автоагенти

26.09.2026 11:13

Microsoft представила оновлену версію Copilot у Microsoft 365. 🚀 Ключова новація — розділ Code, де користувачі без навичок програмування створюють застосунки та дашборди просто текстовими промптами. Новий сервіс Copilot Managed Runtime автоматично деплоїть ці AI-застосунки в хмару без ручної конфігурації. 💡 Чому це важливо: Microsoft робить ставку на повну демократизацію розробки: аналітик може побудувати інструмент за 5 хвилин, а інженер пізніше підключить його до зовнішніх сервісів через SDK. 🧩 ⚒️ Як спробувати: Якщо у вас є підписка на Microsoft 365, оновіть Copilot — новий інтерфейс із розділами Code та Chat вже доступний. Почніть із простого запитання в режимі Chat для створення документу або спробуйте згенерувати міні-ап в Code. 🔗 Джерело: SiliconAngle AI 📲 Ще новини AI українською
