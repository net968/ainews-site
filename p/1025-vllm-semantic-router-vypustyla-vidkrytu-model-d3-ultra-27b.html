vLLM Semantic Router випустила відкриту модель d3-ultra (27B)

27.10.2026 15:00

Команда vLLM Semantic Router представила d3-ultra — відкриту мультимодальну модель на 27B параметрів. ⚡ Вона одразу обробляє текст, зображення та відео, повертаючи ймовірності для всіх варіантів відповіді. На внутрішньому тесті SR-Text модель показала результат 87.2. 💡 Чому це важливо: Відкриті вартісні моделі для семантичного маршрутизування дозволяють будувати складні AI-пайплайни без залежності від закритих API та з повним контролем над даними. ⚒️ Як спробувати: Завантажте ваги моделі та інтегруйте її через vLLM для тестування на власних даних 👀 — це ідеальний інструмент для оптимізації вартості інференсу у великих системах. 🔗 Джерело: MarkTechPost 📲 Ще новини AI українською
