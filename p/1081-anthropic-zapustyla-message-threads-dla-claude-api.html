Anthropic запустила message threads для Claude API

03.11.2026 07:00

Anthropic представила бета-функцію message threads, яка дозволяє агентам не пересилати всю історію діалогу з кождим запитом. ⚡ Замість цього агент передає повну розмову один раз, а далі лише нові повідомлення та ID останньої відповіді моделі. За даними компанії, це скорочує час очікування відповіді на 35% у дуже довгих сесіях (500K–1M токенів). 💡 Чому це важливо: Функція економить час, а не гроші — ціни та ліміти незмінні, але вона критично прискорює роботу агентів, які роблять сотні запитів поспіль. 🎯 Що це означає на практиці: Варто інтегрувати threads у свої пайплайни вже зараз: бета доступна на всіх моделях Claude та через AWS, Microsoft і Google Cloud. 👀 Тримайте на увазі, що треми зберігаються в пам'яті лише 5 хвилин після останнього запиту, тож зберігати копії розмов має розробник. 🔗 Джерело: TNW 📲 Ще новини AI українською
